# Checklist UX — compte sans lieu

Parcours à observer avec un compte Mandala **connecté** mais **rattaché à aucun lieu** (inscription fraîche + « Continuer sans lieu », ou compte qui a quitté tous ses lieux).

Objectif : noter le ressenti et les trous, pas valider la technique.

---

## Préparation

- [ ] Compte test **non admin** (sinon le menu Organisation / Admin fausse la lecture).
- [ ] Aucune appartenance lieu (ou quitter tous les lieux).
- [ ] Une fois : parcours **inscription → Continuer sans lieu**.
- [ ] Une fois : parcours **compte existant déjà sans lieu** (reconnexion).
- [ ] Desktop + mobile (bottom nav solo).

---

## A. Onboarding (juste après inscription)

| # | Action | À noter |
| --- | --- | --- |
| A1 | Écran « Rejoignez un lieu » | Clair ? Pression à rejoindre ? Skip visible ? |
| A2 | Liste lieux publics vide / pleine | Message d’attente compréhensible ? |
| A3 | Lieu sur invitation | Code compréhensible sans doc ? |
| A4 | « Continuer sans lieu » | Sentiment d’avoir « raté » Mandala ou d’entrer librement ? |
| A5 | Transition vers l’app | Chargement, flash, redirection ? |

## Constat produit (référence)

**Landing `/`** : hero + mur/carte (`WallDiscoverSection`) + lieux + promesses + offres.

**Accueil solo app** : 3 boutons (Rejoindre / Annuaire / Ma fiche) — pas de mur, pas de carte, pas d’événements publics.

Écart principal : le contenu qui vend Mandala est **dehors** ; une fois connecté sans lieu, l’app **se vide**.
